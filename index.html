Connect Google Sheets

One-time setup · Your data stays in your Google account
1
Go to Google Cloud Console

Open console.cloud.google.com and sign in.

2
Create a new project

Click the project dropdown → New Project. Name it PlantForce. Click Create.

3
Enable the Google Sheets API

Go to APIs & Services → Library. Search Google Sheets API and click Enable.

4
Create an OAuth 2.0 Client ID

Go to APIs & Services → Credentials → Create Credentials → OAuth client ID.
· Application type: Web application
· Name: PlantForce
· Authorized JavaScript origins: add https://yourusername.github.io
Click Create and copy the Client ID.

5
Configure OAuth consent screen

Go to APIs & Services → OAuth consent screen. Choose External, fill in app name PlantForce and your email. Add yourself and any viewers as Test users.

6
Host on GitHub Pages

· Create a repo (e.g. plantforce), upload this file as index.html
· Go to Settings → Pages → Branch: main → Save
· Your app will be at https://yourusername.github.io/plantforce/
· Share that URL with anyone who needs view/edit access — they'll sign in with their own Google account (must be added as a Test user above)

7
Enter your Client ID below

Paste the Client ID from Step 4.

🔒 Privacy: Your Client ID and all field data stay entirely within your Google account. PlantForce communicates directly between your browser and Google's API — no data passes through any third-party server.
