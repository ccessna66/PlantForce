Connect to Field Progress Tracker

Sign in with Google to access the shared field tracker
1
Go to Google Cloud Console

Open console.cloud.google.com and sign in.

2
Create a project and enable Sheets API

New Project, name it PlantForce. Then APIs & Services → Library, search Google Sheets API, click Enable.

3
Create an OAuth 2.0 Client ID

Credentials → Create Credentials → OAuth client ID
Type: Web application   Name: PlantForce
Authorized JavaScript origins: https://yourusername.github.io
Copy the Client ID when done.

4
Add all users to OAuth consent screen

APIs & Services → OAuth consent screen → Test users → + Add Users. Add the Gmail address of every person who needs access.

5
Connect — this creates the shared spreadsheet

After connecting, a popup will show the Sheet ID to share with other users.

The spreadsheet is created in your Google account. Share the Sheet ID and Client ID with other users so they can connect to the same data.
1
Get the Client ID and Sheet ID from the owner

The owner will provide both after completing first-time setup.

2
Enter both IDs below
Make sure the owner has added your Gmail address to the Test users list in Google Cloud Console, otherwise sign-in will be blocked with a 403 error.
